    How to play

    Each turn both players secretly lock in one piece, then both are revealed. Your opponent's pieces stay hidden. You are never told what they hold or have lost, so the game is about memory, odds and reading your opponent.

    You win when

    • Your opponent's last Monarch is taken.

    If both Monarchs fall in the same round it is a draw. Having no piece that can beat the opponent's does not end the game.

    Equal pieces destroy each other. The winning piece returns to hand and can be used again; only the Dragon is spent. A Joker becomes the piece it meets; both then return to hand. The Joker can never be destroyed before it transforms.
