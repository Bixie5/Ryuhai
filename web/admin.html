Shop admin

Add new piece skins, set their price in bananas, or change and remove them later. Changes show up in every player's Shop the next time they open it.

Enter admin key

The key is printed in the terminal when the server starts. The link printed there already includes it.

Always-on copy

Players' games load the shop from this address every time they open, so new skins appear even when this computer is off. Paste it into web/config.js as shopUrl (once), then rebuild the app.

New skins can take up to a minute to show up for players.

Right now skins are saved on this computer only, so they only appear in the game while this computer's server is running. To keep them available all the time, set up the free GitHub copy: make a public repository, create an access token for it, and start the server with REMOTE_GITHUB_REPO and REMOTE_GITHUB_TOKEN set. Step by step in DEPLOY.md (section "Always-on shop").
