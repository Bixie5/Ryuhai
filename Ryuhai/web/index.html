    How to play

    Each turn both players secretly lock in one piece, then both are revealed. Your opponent's pieces stay hidden. You only see how many they hold and which have fallen, so the game is about memory, odds and reading your opponent.

    You win when

    • The opponent has no pieces left.
    • The opponent has no piece that can beat any of yours.
    • The opponent's Monarch is taken.

    Equal pieces destroy each other. The winning piece returns to hand and can be used again; only the Dragon is spent. A Joker becomes the piece it meets; both then return to hand. The Joker can never be destroyed before it transforms.

    Server

    Online and room play connect to a Ryuhai server. When you open the game from the server's own address this is filled in for you. In the Android app, type the address shown when the server starts, for example 192.168.1.20:3000.
